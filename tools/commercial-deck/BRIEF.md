# Buyniverse Commercial Presentation (HyperFrames Dual-Mode)

## Purpose
A 10-scene 1920x1080 HyperFrames composition designed for two simultaneous commercial uses:
1. **Interactive Executive Deck**: Open `index.html` in any browser (or `npm run dev`) to present live in meetings with keyboard navigation (`←` / `→` / `Space`), scene jump, responsive viewport scaling, and instant `ES / EN` language switching.
2. **Deterministic MP4 Video**: Run `npm run check` and `npm run render` via `hyperframes@0.8.79` to capture frame-accurate 1080p MP4 video for asynchronous sharing over email, LinkedIn, or WhatsApp.
